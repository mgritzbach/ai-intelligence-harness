The Problem
02 / 05

AI models fabricate facts.
We built a system that makes it impossible.

📉
Hallucinated Market Data
Models confidently recall prices from training — often months or years stale — presenting them alongside live news as if current.
"EUR/USD = 1.09" reported with full confidence. The real rate was 1.16 — a 6.4% error on a critical metric.
📰
Stale or Invented Stories
Without date verification, agents cite events from their training window and present them as current news — indistinguishable from live reporting.
A story from 18 months ago in a "this week" briefing — no date, no flag, no warning to the reader.
🔗
Fabricated Source URLs
Models generate plausible-looking URLs that are dead links, paywalled pages with no article body, or entirely invented domains.
Source: reuters.com/article/xyz — returns 404. The story was never verified as real.
🛡️
Our Response
15-agent parallel architecture · Mandatory URL fetching · Article date extraction · Verbatim proof-of-reading · Dual sourcing · Independent higher-token verification agent

Verification Engine
04 / 05

Six hard rules.
Zero tolerance for fabrication.

Applied by every low-token agent — no exceptions
R1
No Numbers from Memory
Every figure must come from a fetched URL. Model recall is banned.
R2
Verify Every URL by Fetching
All source URLs fetched and confirmed live. Dead links = story rejected.
R3
No Stories from Training Data
All stories must originate from a live web search result.
R4
Extract Article Date from the Page
Publication date found in HTML. Stories outside window = rejected.
R5
Include One Verbatim Quote
One exact sentence copied word-for-word. Proves the agent read the source.
R6
Two Sources for Tier 1 Stories
Top stories need a second independently-fetched URL. Else auto-downgraded.
